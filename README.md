# GDS Game Development Workshops
This GitHub repository contains all the teaching material and example projects for our gamedev workshops! 

## Where to Start?
For anyone completely new to these workshops, you can learn more about what to expect from them within the [Introduction](Material/Week-1/workshop_introduction.md).
### Beginners
Anyone that's completely new to gamedev/Godot, please start with this [beginner guide](Material/Week 1/getting_started.md)!
### More experienced devs
Anyone else who already has some Godot experience, please start with having a look at [some good practices](Material/Week-1/good_practices.md). It'll help you code a lot more efficiently! After that, you can start with the [platformer](/Material/Week-1/basic_platformer.md).
